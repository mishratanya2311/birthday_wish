# Dreamy Birthday Card 💗🎂

A little birthday surprise made with **HTML, CSS, and JavaScript** --- a
dreamy, interactive birthday-card website you can personalize for your
bestie or someone special.

Instead of sending only a birthday message, create a tiny digital world
filled with memories, sweet notes, and a little sparkle. The idea is to
make it easy for anyone to turn code into a thoughtful birthday gift and
create one for someone they love.

## ✨ What's inside?

-   **A magical countdown intro** with a celebratory reveal.
-   **Six interactive pages** that feel like a little birthday story.
-   **A photo memory lane** with three photo spots.
-   **Bestie awards** to celebrate their personality.
-   **Friendship timeline** for meaningful moments and inside jokes.
-   **A heartfelt letter** that can be personalized.
-   **A final birthday wish** with an interactive reveal and floating
    sparkles.
-   **Dreamy pink and butter-yellow styling**, glowing details, and
    gentle animations.
-   **Responsive layout** designed to work on desktop and mobile
    screens.

## 🛠️ Built with

-   HTML
-   CSS
-   Vanilla JavaScript

No framework or build step is required.

## 🚀 Run it locally

1.  Download or clone this project.
2.  Keep `birthday_card.html` and your photo files in the same folder.
3.  Open the folder in VS Code.
4.  Open `birthday_card.html` directly in your browser, or use the
    **Live Server** extension in VS Code.

## 🖼️ Add your own photos

The memory page looks for these three image files:

-   `photo1.png`
-   `photo2.png`
-   `photo3.png`

Put your own images in the same folder as `birthday_card.html` and name
them exactly as shown, or update the three `src` values in the HTML to
match your filenames.

For example:

``` html
<img src="photo1.png" alt="Memory photo 1">
```

Make sure the filename and extension match exactly.

## 💌 Personalize the card

Make the card feel like *their* story:

1.  **Change the birthday greeting** on the first page.
2.  **Replace the three photos** and update their captions.
3.  **Edit the bestie awards** to match their personality.
4.  **Customize the friendship timeline** with real memories and inside
    jokes.
5.  **Rewrite the letter** in your own words.
6.  **Adjust the final wish** and any colors or text you want.

You can edit the text directly in `birthday_card.html`. To change the
visual theme, look for the CSS variables near the top of the `<style>`
section, including the pink, rose, cream, and butter-yellow colors.

## 🎀 The idea behind the project

This project is about making a birthday gift feel more personal through
code. It turns simple web technologies into an interactive birthday-card
experience that someone can customize for a best friend, sibling,
partner, or anyone special.

The goal isn't just to show code on screen --- it's to inspire you to
make something thoughtful for another person, even if that gift starts
with a few lines of HTML, CSS, and JavaScript.
